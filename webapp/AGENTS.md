# webapp/AGENTS.md

Scoped instructions for the Mattermost plugin webapp bundle. Root rules in `/AGENTS.md` still apply.

## Architecture

- This is a host plugin bundle, not a standalone SPA. Webpack externals (`react`, `redux`, `react-intl`, and related packages) come from the Mattermost webapp.
- Entry point: `src/index.tsx`. `Plugin.initialize(registry, store)` registers RHS, post types, System Console settings, the Agents product, websocket hooks, and slash-command hooks.
- Host bridge: `src/mm_webapp.ts`. Use runtime compatibility checks before assuming newer RHS APIs exist.
- `src/manifest.ts` is generated by `make apply`; never hand-edit it.
- Add plugin HTTP calls to `src/client.tsx` instead of scattering `fetch` through components.
- Plugin Redux state lives at `state['plugins-' + manifest.id]`; see `redux.tsx` and `selectors.ts`.
- Conversation hooks use module-level caches; invalidate through websocket handlers or exported invalidation helpers.

## Commands

- Repo pre-PR gate: `make check`
- Webapp lint/typecheck through repo tooling: `make check-style`
- Auto-fix plus i18n extraction: `make check-style-fix`
- Unit tests: `make test`
- Webapp bundle: `make webapp`
- Deploy to Mattermost: `make deploy`
- Watch rebuild and deploy: `make watch`
- Focused lint: `cd webapp && npm run lint`
- Focused typecheck: `cd webapp && npm run check-types`
- Focused Jest: `cd webapp && npm run test -- --testPathPattern=components/path/test_name.test`
- Production build: `cd webapp && npm run build`

## Conventions

- Use styled-components for new styling; avoid new inline `style={{...}}`.
- User-facing strings use `FormattedMessage` or `useIntl` with `defaultMessage` at the call site.
- Never hand-edit `src/i18n/en.json`; regenerate it with `make i18n-extract` or `make check-style-fix`.
- Prefer the `@/` alias for app imports.
- Co-locate Jest tests as `*.test.ts(x)` and follow existing React Testing Library patterns.
- Do not add a new mocking library.

## Gotchas

- Run `make apply` before direct webapp build/test work when `plugin.json` or manifest data changed.
- Webapp i18n (`webapp/src/i18n/`) and server i18n (`/i18n/`) are unrelated systems.
- `webapp/i18n/en.json` is not the canonical extracted webapp catalog.
- Backend config types mirrored in admin UI live in `components/system_console/plugin_config_types.tsx`.
